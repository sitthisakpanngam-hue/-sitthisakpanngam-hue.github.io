ใช้กล้องมือถือปักมุมแปลงทีละมุม ระบบรวมข้อมูล กล้อง + GPS ให้แม่นกว่าเดิน GPS อย่างเดียว ปิดแปลงแล้วเห็นร่องมันและระบบน้ำหยด 3D ในกล้องทันที

กำลังตรวจว่ามือถือรองรับแบบไหน…
  1. ยืนที่มุมแปลงแรก เล็ง วงเป้ากลางจอ ไปที่โคนเสามุม (หรือก้มส่องที่เท้า)
  2. ยืนนิ่งจนขึ้น "พร้อม" แล้วกด 📍 ปักมุม
  3. เดินไปมุมถัดไปตามขอบแปลง ทำซ้ำจนครบทุกมุม
  4. กด ✔ ปิดแปลง — ระบบคำนวณพื้นที่ วางร่อง แบ่งโซน และแสดง 3D

แนวร่องปลูก

แนวร่องทางเดินดวงอาทิตย์วันนี้ทิศน้ำไหล (ลาดลง)
    เปรียบเทียบแนวอื่น

    คะแนนรวมจาก ความลาด (กันดินพัง/แรงดันน้ำ), แสงแดดตลอดปีจากตำแหน่งดวงอาทิตย์จริงของพิกัดนี้, จำนวนหัวท้ายร่อง และความยาวเทปน้ำหยด — น้ำหนักเรื่องความลาดเพิ่มขึ้นอัตโนมัติเมื่อพื้นลาดมาก

    สรุประบบ

    📏 วัดระดับพื้นจริง ยังไม่มี

    ความสูงจากดาวเทียม/DEM หยาบ (±2–5 ม.) วัดจริงด้วย สายยางระดับน้ำ หรือ กล้องมือถือ อย่างน้อย 3 จุด แล้วระบบจะใช้ค่าจริงสร้างพื้น 3D คำนวณความลาด แรงดัน และโซนให้ใหม่

    วิธีวัดด้วยสายยางระดับน้ำ (แม่น ±1 ซม.)
    1. สายยางใสยาว 20–30 ม. เติมน้ำเต็ม ไล่ฟองอากาศออก
    2. คนที่ 1 ถือปลายสายตั้งตรงที่ จุดที่รู้ระดับแล้ว (จุดแรก = จุดอ้างอิง เช่น ข้างปั๊ม) วัดว่าระดับน้ำสูงจากพื้นกี่ ซม.
    3. คนที่ 2 ถือปลายอีกข้างที่จุดใหม่ รอน้ำนิ่ง วัดระดับน้ำจากพื้นกี่ ซม.
    4. ใส่ 2 ตัวเลขนี้ในแอป ระบบคำนวณให้ว่าสูง/ต่ำกว่ากี่ ซม.
    5. วัดที่มุมแปลง หัว–ท้ายร่อง จุดสูงสุด จุดต่ำสุด และจุดที่น้ำขัง

    กราฟการเติบโตและผลผลิต
    ความสูงมาตรฐาน (ม.)วัดจริงวันนี้
    ผลผลิตศักยภาพ (ตัน/ไร่)คาดตามการให้น้ำ

    เส้นมาตรฐานเป็นค่าประมาณทั่วไปของมันสำปะหลังที่ได้น้ำพอ ใช้เพื่อเปรียบเทียบแนวโน้ม ไม่ใช่ผลผลิตที่รับประกัน

    ภาพดาวเทียม Google Maps

    ใช้ภาพดาวเทียม Google Maps, ความสูง–ความชันจาก Google Elevation และพยากรณ์จาก Google Weather ต้องใช้ API key ของคุณเอง (มีโควตาใช้ฟรีรายเดือน)

    วิธีขอ API key (ประมาณ 10 นาที)
    1. เข้า console.cloud.google.com ด้วยบัญชี Gmail → สร้างโปรเจกต์ใหม่ → ผูกบัตรเครดิตที่เมนู Billing (มีโควตาฟรีทุกเดือน ใช้ไม่เกินก็ไม่เสียเงิน)
    2. เมนู APIs & Services → Library เปิดใช้ Maps JavaScript API (แผนที่ดาวเทียมตอนวัดแปลง) และ Map Tiles API (ภาพดาวเทียมรอบไร่ในภาพ 3D) · ถ้าต้องการเพิ่ม เปิด Elevation API และ Weather API
    3. Credentials → Create credentials → API key แล้วคัดลอกมาวางช่องด้านบน กด "บันทึกและทดสอบ"
    4. สำคัญ — กันคนอื่นเอาคีย์ไปใช้: แก้คีย์ → Application restrictions = Websites ใส่ sitthisakpanngam-hue.github.io/* · API restrictions เลือกเฉพาะ API ที่เปิดไว้
    5. กันเสียเงิน: ตั้ง Budget alert ที่ 1 บาท และตั้งเพดาน (Quotas) ของแต่ละ API ให้ต่ำกว่าโควตาฟรี

    โควตาฟรีต่อเดือนตามราคาของ Google: Dynamic Maps 10,000 ครั้ง · 2D Map Tiles 100,000 ครั้ง · Elevation 5,000 ครั้ง · Weather 10,000 ครั้ง · แอปเก็บคีย์ไว้ในเครื่องนี้เท่านั้น ไม่ส่งไปที่อื่น และไม่ติดไปกับไฟล์สำรอง

    ⚠️ หน้าตัวอย่างใน Claude บล็อกการเชื่อมต่อ Google ทั้งหมด ต้องเปิดเว็บที่ฝากไว้บน https เท่านั้น · key เก็บในเครื่องนี้เท่านั้น
