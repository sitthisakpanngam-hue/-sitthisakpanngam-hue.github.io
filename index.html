เชื่อมต่อ Google

ใช้ภาพดาวเทียม Google Maps, ความสูง–ความชันจาก Google Elevation และพยากรณ์จาก Google Weather ต้องใช้ API key ของคุณเอง (มีโควตาใช้ฟรีรายเดือน)

วิธีขอ API key (ประมาณ 5 นาที)
  1. เข้า console.cloud.google.com → สร้างโปรเจกต์ และผูกบัญชีเรียกเก็บเงิน (มีโควตาฟรีรายเดือน)
  2. เมนู APIs & Services → Library เปิดใช้ Maps JavaScript API, Elevation API และ Weather API
  3. Credentials → Create credentials → API key แล้วคัดลอกมาวางด้านบน
  4. สำคัญ: ตั้ง Application restrictions เป็น Websites ใส่โดเมนเว็บของคุณ (เช่น xxxx.netlify.app/*) และจำกัดเฉพาะ 3 API ข้างบน ป้องกันคนอื่นนำ key ไปใช้
  5. ตั้ง Budget alert ใน Billing เพื่อแจ้งเตือนก่อนเกินงบ

โควตาฟรีต่อเดือนตามราคาของ Google: Dynamic Maps 10,000 ครั้ง · Elevation 5,000 ครั้ง · Weather 10,000 ครั้ง ระบบเรียกข้อมูลเฉพาะตอนเปิดแอป วัดแปลง หรือกดโหลดใหม่
